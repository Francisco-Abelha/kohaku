Last updated 13 November 2026.

Kohaku is a concept store: a portfolio project, not a real business. No orders are taken, nothing is shipped and nobody is charged, so there is nothing to refund or return.

## Test checkout

When the test checkout opens, it will run in Stripe's test mode. It accepts only test card numbers, declines real cards and moves no money. Any "order" you place there is a demonstration and won't be fulfilled.

## If something looks wrong

If you ever see a charge you think came from this site, it didn't: this site cannot take payments. Contact your bank about it.
